## English

[English](#english) | [한국어](#한국어) | [Español](#español) | [日本語](#日本語)

### Introduction

**Seekstep** is a browser extension designed to let you move forward and backward in **5-second or 3-second intervals** across various OTT and streaming services, including YouTube and Netflix.

It is especially useful for **English listening practice**, because it makes it easy to replay short sections you missed and review them quickly using only the keyboard.

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `←` | Back 5 seconds |
| `→` | Forward 5 seconds |
| `[` | Back 3 seconds |
| `]` | Forward 3 seconds |

### Features

- Supports multiple OTT and streaming services
- Keyboard shortcuts for quick seeking
- Two seek intervals: 5 seconds and 3 seconds
- Useful for English listening, shadowing, and dictation practice

### Installation

1. Clone this repository or download it as a ZIP file.
   ```bash
   git clone https://github.com/spak432/seekstep.git
   ```
2. Open `chrome://extensions` in Chrome.
3. Turn on Developer mode.
4. Click **Load unpacked** and select the project folder.

### Usage

Open a supported video page and use the shortcuts above to move backward or forward.

### Introducción

**Seekstep** es una extensión del navegador diseñada para avanzar y retroceder en intervalos de **5 o 3 segundos** en varias plataformas OTT y de streaming, incluyendo YouTube y Netflix.

| Tecla | Acción |

| `]` | Avanzar 3 segundos |

### Características

- Compatible con múltiples servicios OTT y de streaming
- Atajos de teclado para buscar rápidamente
- Dos intervalos de salto: 5 segundos y 3 segundos
- Útil para practicar listening, shadowing y dictado en inglés

### Instalación

1. Clona este repositorio o descárgalo como ZIP.
   ```bash
   git clone https://github.com/spak432/seekstep.git
   ```
2. Abre `chrome://extensions` en Chrome.
3. Activa el Modo desarrollador.
4. Haz clic en **Cargar descomprimida** y selecciona la carpeta del proyecto.

## 日本語

[English](#english) | [한국어](#한국어) | [Español](#español) | [日本語](#日本語)

### 紹介

**Seekstep** は、YouTube や Netflix をはじめとするさまざまな OTT・ストリーミングサービスで、**5秒または3秒**単位で前後に移動できるブラウザ拡張機能です。

特に **英語のリスニング学習** に便利で、聞き取れなかった部分をすぐに短い区間で再生し直せます。マウスを使わず、キーボードだけで素早く操作できます。

### ショートカットキー

| キー | 動作 |
|------|------|
| `←` | 5秒戻る |
| `→` | 5秒進む |
| `[` | 3秒戻る |
| `]` | 3秒進む |

### 主な機能

- 複数の OTT・ストリーミングサービスに対応
- キーボードショートカットで素早く移動
- 5秒 / 3秒 の2種類の移動間隔
- 英語のリスニング、シャドーイング、ディクテーション学習に最適

### インストール

1. このリポジトリをクローンするか、ZIP でダウンロードします。
   ```bash
   git clone https://github.com/spak432/seekstep.git
   ```
2. Chrome で `chrome://extensions` を開きます。
3. **デベロッパーモード** を有効にします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、プロジェクトフォルダを選択します。

### 使い方

対応している動画ページを開き、上記のショートカットキーを使用して前後に移動します。
